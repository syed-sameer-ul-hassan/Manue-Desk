# Contributing to Manue Desk

Thank you for your interest in contributing to **Manue Desk**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

---

##  How to Contribute

1. **Fork the Repository**: Create your own fork of [syed-sameer-ul-hassan/Manue-Desk](https://github.com/syed-sameer-ul-hassan/Manue-Desk).
2. **Clone Your Fork**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Manue-Desk.git
   cd Manue-Desk
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make Your Changes**: Keep code clean, formatted, and documented.
5. **Test Your Changes**:
   ```bash
   cargo build
   cargo run
   ```
6. **Commit & Push**:
   ```bash
   git commit -m "Add feature XYZ"
   git push origin feature/my-new-feature
   ```
7. **Open a Pull Request**: Submit a Pull Request targeting the `main` branch.
