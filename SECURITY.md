# Security Policy

## Supported Versions

Only the latest release version of **Manue Desk** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :✔:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Manue Desk**, please do not disclose it publicly on GitHub issues.

Instead, please report security issues directly to the maintainer:

- **Email**: [manuedesk@orildo.sbs](mailto:manuedesk@orildo.sbs)
- **Developer**: Syed Sameer Ul Hassan
- **Website**: [manuedesk.orildo.sbs](https://manuedesk.orildo.sbs)

Please include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Your contact information for follow-up questions.

You will receive an initial response acknowledging your report within 48 hours.
